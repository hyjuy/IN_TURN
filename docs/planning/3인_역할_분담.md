# 3인 기능별 개발 분담

세 명 모두 화면·백엔드·데이터를 필요한 범위에서 개발합니다. 아래 담당은 기능의 완성과 인계를 책임지는 기준이며, 특정 폴더의 독점 소유를 뜻하지 않습니다.

## 1. 게임 진행과 상태

- 시작·일정·선택 화면과 게임 진행 API를 구현합니다.
- 날짜 전환, 체력·스트레스 등 게임 수치, 상태 저장과 초기화를 구현합니다.
- Day 1과 Day 5의 진행 흐름 및 관련 테스트를 담당합니다.
- 주요 작업: `frontend/`, `backend/app/api/`, `backend/app/game/`, `backend/tests/`

## 2. NPC 대화와 기억 분기

- NPC 대화 화면과 대화 API, LLM 연결 및 실패 시 대체 대사를 구현합니다.
- 상사·선배 설정과 관계 변화를 작성하고, Day 2의 선택이 Day 4에 영향을 주는 분기를 구현합니다.
- 기억 일관성, 응답 오류와 분기 재현을 검증합니다.
- 주요 작업: `frontend/`, `backend/app/agents/`, `backend/app/services/`, `data/characters/`, `data/scenarios/`

## 3. 미션과 행동 기반 보고서

- 생산기술 업무 미션 화면과 관련 API, 행동 기록 및 결과 보고서 생성을 구현합니다.
- Day 2~4 업무자료·선택지와 평가 사례를 작성하고, 공식 NCS 준거 3~5개와 출처·이용 조건을 확인합니다.
- 행동 로그와 확인된 준거를 연결하고, 근거 부족·관찰 기회 없음 및 결과의 한계를 표시합니다.
- 주요 작업: `frontend/`, `backend/app/`, `data/ncs/`, `data/evaluation/`, `data/scenarios/`, `docs/research/`

## 함께 진행

- 시작 전에 게임 상태, 이벤트·선택지, 행동 근거와 API 형식을 합의하고 공유합니다. 공통 파일을 수정할 때는 먼저 조율합니다.
- 각 담당자는 자신의 기능에 필요한 콘텐츠와 테스트를 함께 작성합니다. NCS 확인과 시나리오 검토는 세 명이 나눠 지원합니다.
- 5일 완주, NPC 2명, 기억 기반 분기와 보고서를 먼저 연결합니다. 통합 테스트, 사용자·현직자 피드백, 발표·시연 준비는 세 명이 함께 나눕니다.
- 각자 작업 브랜치와 PR을 사용합니다. 일정과 인계 조율 담당자는 팀에서 정합니다.
